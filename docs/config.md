# How to Run the Current Version

### 1. Clone the repository

```powershell
$ git clone https://github.com/fcl2002/Autonomous-Taxi.git
$ cd autonomous-taxi
$ cd vazy-app
```

This file contains the basic commands required to config and run the project on Windows using VS Code.

## 1. Instal dependencies

```bash
$ npm install
```

## 2. Building the project

```bash
$ npx expo run:android
```

## 3. Running

```bash
$ npx expo start
```
